# 출처

`SKILL.md`는 [mattpocock/skills](https://github.com/mattpocock/skills)의
`skills/productivity/grilling/SKILL.md`를 가져와 고친 것이다. 처음 가져온 커밋은 `95249b0`(2026-10-07)이고,
`7739eae`(2026-10-29, subagent를 fresh context로 띄우기)까지 반영했다.
원본은 MIT이며, 이 디렉터리도 MIT로 유지한다. 원본과 질문 형식·종료 방식이 달라 같은 스킬이 아니다.

| 변경 | 내용 |
|---|---|
| 수정 | 사실 확인은 직접 도구로 먼저, subagent는 넓은 탐색에만 (원본: 사실은 subagent로) |
| 삭제 | 원본의 'yes 하나로 추천 수락' 문구 (습관적 yes를 부름) |
| 추가 | 질문마다 '지금 정하는 것'(전체 중 위치·영향), 선택지별 결과를 쉬운 말로, 추천 이유, ⚠️ 되돌리기 어려움 표시 |
| 추가 | 라운드 시작에 '만드는 것 / 지금까지 정한 것' 2줄 |
| 추가 | 되돌리기 쉬운 사소한 결정은 묻지 않고 기본값으로 정해 목록에만 적음 |
| 추가 | 사실에 기댄 추천 답에 `confirmed` / `hypothesis` 표기 |
| 추가 | 종료 시 결정 기록(결정·이유·버린 대안과 이유·영향)을 파일로 남기고, 시작할 때 기존 기록을 읽음 |
| 추가 | description에 한국어 트리거, 범위가 모호한 작업(SOW·마이그레이션·업그레이드 계획) |
