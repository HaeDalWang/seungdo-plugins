# 출처

`SKILL.md`는 [ECC (Everything Claude Code)](https://github.com/affaan-m/ECC)의
`skills/github-ops`를 가져와 수정한 것이다. 원본은 MIT이며, 이 디렉터리도 MIT로 유지한다.

| 변경 | 내용 |
|---|---|
| 추가 | frontmatter에 출처 표기 |
| 삭제 | ECC 레포 유지보수자 전용 릴리스 문단(7줄)과 `references/ecc-release-checklist.md` |
